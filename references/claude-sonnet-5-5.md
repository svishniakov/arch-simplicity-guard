# Дополнение для Claude Sonnet 5.5

Применяй для `claude-sonnet-5-5` вместе с [core.md](core.md).

- Заверши порученную проверку с выводом и существенными замечаниями. Не останавливайся на предложении проверить материалы, если они доступны и их чтение разрешено.
- После проверки затронутых требований остановись. Не начинай собственные дополнительные раунды review, hardening или делегирования без конкретной нерешённой проблемы либо требования процесса.
- Не превращай предложение упростить архитектуру в разрешение создавать новые документы, тестовые системы или менять код. При разрешённых изменениях проверь затронутое поведение; не расширяй работу ради полноты оформления.

Адаптация от 2026-10-24. Основа — исходная инструкция гейта; рекомендации по завершению работы, границам инициативы и проверкам взяты из [Prompting Claude Sonnet 5.5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5-5). Их применение к архитектурному review — решение проекта. Дополнение не меняет effort. Поведенческая проверка на Sonnet не проведена.
