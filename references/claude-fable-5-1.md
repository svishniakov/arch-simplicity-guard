# Дополнение для Claude Fable 5.1

Применяй для `claude-fable-5-1` вместе с [core.md](core.md).

- Заверши всю порученную проверку; в итоговом ответе охвати её результат, а не только последнее действие. Не запрашивай повторное разрешение на уже порученное чтение или анализ.
- Не добавляй соседние исправления, расширения и постоянные тестовые материалы только потому, что их можно сделать одновременно. Нужность проверки определяется конкретным изменённым поведением и действующими требованиями проекта.
- Если вывод зависит от меняющейся возможности платформы или версии API, проверь её по актуальному первичному источнику. Для устойчивого факта не нужен отдельный поиск.
- Дай краткое обоснование существенных замечаний. Не превращай отчёт в пересказ всех прочитанных материалов.

Адаптация от 2026-10-24. Основа — исходная инструкция гейта. [Prompting Claude Fable 5.1](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-1) описывает завершение задач, ограничение сопутствующих изменений и тестов, плотность текста и поиск. Применение этих рекомендаций к гейту — решение проекта; настройки модели сохраняются. Поведенческая проверка на Fable не проведена.
